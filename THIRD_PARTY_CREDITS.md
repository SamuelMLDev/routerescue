# Third-party notices and credits

**Runtime dependencies:** None. RouteRescue runs using Node.js built-in modules and web platform APIs. It does not bundle fonts or stock imagery.

**Development/test tools used:** Node.js 22.16.0 (MIT-licensed components and various Node.js dependency licences); Chromium and Playwright for screenshot-based inspection (not bundled). All icons, layouts, route map geometry, fictional addresses and brand marks were created specifically for this project. The SVG icon paths are original simple line drawings.

**Open technical standard:** Model Context Protocol 2025-11-25 is used over Streamable HTTP. The local JSON-RPC transport was implemented in the project; the official MCP SDK is not imported. Specifications: https://modelcontextprotocol.io/specification/2025-11-25/basic/transports and https://modelcontextprotocol.io/specification/2025-11-25/server/tools .

**No Amazon assets or trademarks** are included in the interface. “Alexa+ style simulator” describes the chosen official hackathon pathway, not an endorsement or official Alexa+ integration.

**Data:** All names, delivery addresses and city geometry are fictional. No real customer data, downloaded datasets or remote map tiles are used.
